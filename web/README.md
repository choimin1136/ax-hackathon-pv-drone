# 대시보드 첫 화면

Node.js 20 이상에서 추가 패키지 설치 없이 실행합니다.

```bash
node tools/serve.mjs
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다. 기본 바인딩은 로컬 컴퓨터만 접속 가능한 `127.0.0.1`입니다. 이 서버는 개발 미리보기용이며 공개 서비스 배포용이 아닙니다.

## 구현 범위

- 6×4 구역 지도, 상태 요약, 선택 구역 안내
- 로그인 없는 합성 데이터 미션 재생, 일시정지, 이어서 재생, 초기화, 속도 조절
- 지그재그 경로와 현재 분석 구역, 진행률, 예시 배터리, 최근 이벤트
- 작은 화면 대응과 키보드 구역 선택

첫 화면 프로토타입입니다. 사진·AI 분석 결과·실기체 연결, 후보 승인·제외, 재점검 실행, 가치 환산, 보고서는 아직 구현하지 않았습니다. 지도·후보 개수·경과 시간·배터리는 모두 예시이며 실측값이 아닙니다. 예시의 경과 시간은 재생 속도에 따라 빨라집니다.

## 파일과 연결 지점

- `index.html`: 화면 구조
- `styles.css`: 데스크톱/모바일 스타일
- `mission.mjs`: 합성 시나리오와 상태 전이. README의 `cell_id`, `status`, `candidate_count`, `confirmed_count` 형식을 사용합니다. 향후 백엔드가 반환하는 상태를 연결합니다.
- `app.mjs`: 표시와 사용자 조작. 모델 호출은 하지 않습니다.
- `../tools/serve.mjs`: `web/`만 제공하는 개발 서버

사진 및 API 연결 시 상대 경로를 유지하고, 실제 사진의 메타데이터 제거는 백엔드에서 처리합니다. 미션 결과는 메모리에만 존재하며 새로고침하면 초기화됩니다. 임의의 후보 크기 임계값은 넣지 않았으며 상태는 명시적인 예시 시나리오입니다.

## 검증

```bash
node --test tests/mission.test.mjs
```

브라우저에서는 미션 완료, 일시정지 후 이어서 재생, 초기화, 구역 선택, 경로 표시 전환과 모바일 레이아웃을 확인합니다.

작업은 기능 브랜치에서 진행하고, 확인한 파일만 커밋합니다. GitHub의 PR로 합친 `main`만 팀 서버에 배포합니다. 원본 사진·데이터·실제 좌표·자격 증명은 포함하지 않습니다.
