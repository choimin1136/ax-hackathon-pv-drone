# 대시보드 첫 화면

Node.js 20 이상에서 추가 패키지 설치 없이 실행합니다.

```bash
node tools/serve.mjs
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다. 기본 바인딩은 로컬 컴퓨터만 접속 가능한 `127.0.0.1`입니다. 이 서버는 개발 미리보기용이며 공개 서비스 배포용이 아닙니다.

## 구현 범위

- 6×4 구역 지도, 상태 요약, 선택 구역 안내
- 로그인 없는 합성 데이터 미션 재생, 일시정지, 이어서 재생, 초기화, 속도 조절
- 지그재그 경로와 현재 분석 구역, 진행률, 예시 배터리, 최근 이벤트
- 작은 화면 대응과 키보드 구역 선택

합성 데이터 프로토타입입니다. 선택 구역의 ‘이미지 · 후보 확인’에서 합성 도식, 결함 영역 표시 전환, 후보 선택, 승인·제외·미확인 전환을 사용할 수 있습니다. 실제 사진·AI 분석 결과·실기체 연결, 서버 저장, 재점검 실행, 가치 환산, 보고서는 아직 구현하지 않았습니다. 지도·후보 개수·면적·경과 시간·배터리는 모두 예시이며 실측값이 아닙니다. 예시의 경과 시간은 재생 속도에 따라 빨라집니다.

사람의 확인 결과는 원래 탐지 상태를 덮어쓰지 않고 따로 집계합니다. 모두 제외해도 ‘탐지된 후보 없음’으로 바꾸지 않습니다. 승인 수는 `confirmed_count`에 반영하며 확인 기록은 구역별로 분리됩니다. 새로고침·미션 초기화·완료 후 다시 재생 시 확인 기록이 초기화됩니다. 구역 상태 재판정과 서버 저장 규약은 팀과 확정한 뒤 연결합니다.

## 파일과 연결 지점

- `index.html`: 화면 구조
- `styles.css`: 데스크톱/모바일 스타일
- `mission.mjs`: 합성 시나리오와 상태 전이. README의 `cell_id`, `status`, `candidate_count`, `confirmed_count` 형식을 사용합니다. 향후 백엔드가 반환하는 상태를 연결합니다.
- `app.mjs`: 표시와 사용자 조작. 모델 호출은 하지 않습니다.
- `detail.mjs`: 상세 dialog와 합성 도식·후보 조작. 원본 사진이 아닌 SVG 도식입니다.
- `review.mjs`: 합성 후보와 승인·제외 집계. AI 예측값 또는 정답 라벨로 사용하지 않습니다.
- `../tools/serve.mjs`: `web/`만 제공하는 개발 서버

사진 및 API 연결 시 상대 경로를 유지하고, 실제 사진의 메타데이터 제거는 백엔드에서 처리합니다. 미션 결과는 메모리에만 존재하며 새로고침하면 초기화됩니다. 임의의 후보 크기 임계값은 넣지 않았으며 상태는 명시적인 예시 시나리오입니다.

## 검증

```bash
node --test tests/mission.test.mjs tests/review.test.mjs
```

브라우저에서는 미션 완료, 일시정지 후 이어서 재생, 초기화, 구역 선택, 경로 표시 전환과 모바일 레이아웃을 확인합니다.

작업은 기능 브랜치에서 진행하고, 확인한 파일만 커밋합니다. GitHub의 PR로 합친 `main`만 팀 서버에 배포합니다. 원본 사진·데이터·실제 좌표·자격 증명은 포함하지 않습니다.

## 재점검 대상 선택

미션 아래에서 추천 대상 일괄 선택, 구역별 추가·해제, 전체 해제, 예시 선택 확정을 제공합니다. 점검 대기 구역은 선택할 수 없습니다. 사진 확보 필요·미확인 후보·승인한 주의 구역을 추천하며, 후보를 모두 제외한 구역은 추천에서 빠집니다. 승인만 남은 점검 권장 구역은 정비 판단 대상이므로 자동 재점검 추천에서 제외하지만 직접 선택할 수 있습니다. 이는 시제품 규칙이며 운영 임계값은 아닙니다.

추천 버튼은 현재 선택을 추천 목록으로 교체합니다. 후보 승인·제외 시 추천 이유만 갱신하고 선택은 유지하며, 확정은 해제하여 다시 확인하도록 합니다. 선택 목록은 기존 예시 경로 순서로 표시되며 최적 비행 경로가 아닙니다. 새로고침·초기화·다시 체험하기는 선택을 지웁니다. 실제 재점검 실행, API 전송, 서버 저장은 아직 없습니다.

`reinspection.mjs`에 추천 기준·선택 목록·화면을 모았습니다. `node --test tests/*.test.mjs`로 전체 테스트를 실행합니다.
