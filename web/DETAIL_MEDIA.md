# 셀 상세 합성 이미지와 로딩 상태

이번 범위는 detail.mjs, detail-media.mjs, detail-assets.mjs, detail-media.css와 테스트입니다. app.mjs, mission.mjs, reflight.mjs, reinspection.mjs, 서버 코드는 변경하지 않습니다.

셀 상세에서 독립 합성 사진과 투명 합성 마스크를 같은 640×512 좌표로 표시합니다. 실제 촬영 사진, 모델 출력, 정답 라벨이 아닙니다. 결함 영역 표시를 끄면 원본만 보이며 후보 번호 선택 시 영역을 강조합니다. 후보 없는 구역에는 빈 마스크를 사용합니다.

합성 화면 시험 메뉴: 정상 로딩, 느린 로딩(2.5초), 사진 실패, 마스크 실패. 다시 불러오기는 현재 시험 모드를 반복합니다. 정상 로딩을 선택하면 복구됩니다. 사진이 없거나 불러오는 중이면 후보 조작을 잠급니다. 마스크 실패는 원본과 별도의 실패 안내를 유지합니다. 후보 승인 기록은 모드 전환과 재시도에 유지됩니다. 창을 닫거나 구역을 바꾸면 이전 로딩 응답을 무시합니다. 점검 대기/재촬영 필요 상태는 원래대로 유지합니다.

실제 데이터 연결 시 합성 자산 공급 부분을 교체하되, 사진과 마스크의 좌표·크기 일치, 서버에서 제거한 메타데이터, 상대 경로를 확인해야 합니다. 현재 실제 데이터/API 연결은 없고 실패 시 저장된 실제 결과 복구도 아직 구현하지 않았습니다. 서버·드론 담당의 데이터 형식은 확정하지 않았습니다.

검증: node --test tests/*.test.mjs. 브라우저에서 모드 전환·마스크 숨김·후보 강조·승인 유지·빠른 구역 전환·모바일을 확인합니다.
