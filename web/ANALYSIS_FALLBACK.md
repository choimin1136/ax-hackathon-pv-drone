# 분석 실패 시 합성 저장 결과

셀 상세의 분석 시험에서 정상 분석 예시 / 분석 실패·저장 예시 있음 / 분석 실패·저장 예시 없음을 선택합니다. 700ms 대기 후 결과를 보여주며 ‘분석 다시 시도’는 현재 시나리오를 반복합니다. 정상 모드로 바꾸면 복구됩니다.

저장 예시는 analysis-example.mjs에 포함한 synthetic-demo-v1 구역별 후보 스냅샷이며 실제 과거 모델 응답이나 정답 라벨이 아닙니다. 구역 ID와 후보 수가 일치할 때만 복사본을 반환합니다. 후보가 0개인 정상 결과와 저장 결과 없음 오류를 구분합니다. 결과 없음/대기 중 후보 조작과 마스크는 숨기며, 기존 사람 확인 기록과 지도·가치·보고서는 이전 기록을 유지합니다. 실패를 탐지 후보 없음으로 바꾸지 않습니다.

사진 실패 시에는 대체 분석이 있어도 후보 조작이 잠깁니다. 구역 전환/닫기/초기화 시 늦은 응답은 무시합니다. 승인·제외 기록은 시험 모드 변경/재시도에 보존되고 미션 초기화 시에만 기존 규칙대로 지워집니다.

드론 미션, app.mjs, 서버/API, 저장소 외부 데이터에는 변경이 없습니다. 실제 API 연결 시 사진/분석 버전 등 식별자를 포함한 최종 계약과 실제 저장 결과의 유효성을 팀과 확정해야 합니다. 현재는 상세 화면의 합성 장애 시험이며 실제 서버 캐시나 네트워크 오류 처리가 아닙니다.
