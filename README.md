# ax-hackathon-pv-drone

2026 전남광주 기업 AX 혁신챌린지 해커톤 프로젝트입니다. 드론이 태양광 발전소를 셀 단위로 비행하며 보낸 열화상 사진에서 핫스팟 후보를 찾아, 어느 셀을 먼저 확인하고 다시 점검할지 알려 주는 플랫폼을 만듭니다.

> **상태:** 개발 중. 아래 기능은 구현 계획이며, 완료된 항목은 구현 현황에 표시합니다.
>
> **시뮬레이션:** 실제 드론을 비행하지 않습니다. 발전소 격자와 비행은 가상이고, 열화상 사진과 탐지 결과는 실제 데이터와 모델을 사용합니다.

- **기획 문서:** [system-scenario-plan.md](system-scenario-plan.md)

## 해결하려는 문제

드론 점검에서는 사진을 판독하고, 조치할 곳을 정하고, 애매한 구역을 다시 확인하는 데 시간이 듭니다. 이 프로젝트는 다음 흐름으로 이 과정을 줄이는 것을 목표로 합니다. 현장 수치는 아직 검증 중입니다.

```text
비행 → 핫스팟 분석 → 셀 판정 → 사람 확인 → 애매한 셀만 재비행 → 정비 요청
```

## 주요 기능

| 기능 | 내용 |
|---|---|
| 미션 관제 | 가상 발전소의 비행 경로, 진행률, 셀 상태 표시 |
| 핫스팟 분석 | 열화상 사진에서 핫스팟 후보와 마스크 표시 |
| 셀 판정 | 후보 수와 크기로 정상, 주의, 점검 권장 구분 |
| 사람 확인 | 후보를 근거 사진과 함께 승인 또는 제외 |
| 재점검 | 주의 또는 미확정 셀만 골라 재비행 미션 구성 |
| 체험 모드 | 로그인 없이 저장된 미션 결과 재생 |

셀 판정은 학습된 값이 아니라 규칙 기반입니다. AI 결과는 참고용이며, 최종 판단은 사람이 합니다.

## 시스템 구조

```text
웹 플랫폼 ── 미션 업로드 ──→ ArduPilot SITL
  ↑   │     ←─ MAVLink 위치·상태 ──┘
  │   │                     │ MISSION_ITEM_REACHED
  │   │                     ↓
  └───┼ 이미지 + 셀 정보 ── RPi 모사 프로그램
      │
      ↓
AIStream 서빙 (태양광 결함 분할 모델)
```

| 구성 요소 | 역할 | 위치 |
|---|---|---|
| 웹 플랫폼 | 관제 화면, 분석 결과, 사람 확인 | 팀 서버 |
| ArduPilot SITL | 비행 시뮬레이션 | 팀 서버 |
| RPi 모사 프로그램 | 웨이포인트 도착 시 사진 전송 | 팀 서버 |
| AIStream 서빙 | 핫스팟 탐지 | 전남 AI 오픈플랫폼 |

SITL을 사용할 수 없는 환경에서는 저장된 비행 기록을 재생합니다.

## 데이터와 모델

- **데이터:** AI Hub [신재생 에너지 발전 설비 결함진단 멀티모달 데이터](https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=71923)의 태양광 열화상 사진
- **모델:** 대회에서 제공한 AIStream 결함진단 서빙

데이터와 사진은 이 저장소에 포함하지 않습니다.

## 샘플 측정 결과

샘플 19장(정상 라벨 16장, 결함 라벨 3장)을 2026-11-06에 측정했습니다. **표본이 작아 경향만 참고할 수 있습니다.**

| 항목 | 결과 |
|---|---|
| 처리 시간 | 장당 중앙값 약 0.9초 |
| 27px 이상 라벨 핫스팟 | 18/18 탐지 |
| 25px 이하 라벨 핫스팟 | 0/8 탐지 |
| 정상 라벨 사진 | 16장 중 12장에서 후보 탐지 |

탐지 일치는 위치가 대략 맞는지만 보는 느슨한 기준입니다. 작은 핫스팟을 놓칠 수 있으므로 "이상 없음"을 안전 보증으로 볼 수 없습니다.
